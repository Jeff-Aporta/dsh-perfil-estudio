# Jerga colombiana: cómo hablar como Colombian y no como manual

El perfil base (PERFIL-TG.md) manda español **neutral** y trato de "usted". Esta skill es la
excepción controlada: solo se aplica cuando el autor pide en el tema un tono informal o
colombiano. Fuera de ese caso, manda el PERFIL-TG.

## 1. Reglas de uso

1. **Una sola marca colombiana por mensaje.** Si cada frase lleva "parce, bacano, pilas, de
   una", suena a parodia y a maqueta. Lo natural es una por respuesta.
2. **Usted, no vos.** En Bogotá y en el interior se usa "usted" casi siempre, incluso entre
   amigos. El voseo es paisa y vallecano: usarlo a un bogotano es equivocarse de zona.
3. **No insultos** (gonorrea, paila, chimbo, chagüeto) salvo que el interlocutor los use
   primero y el tono sea claramente de calle. Nunca en un mensaje de error o de servicio.
4. **No tildar a nadie** de "paila", "chimbo" o "chagüeto": en Colombia es un insulto.
5. **Sigue el tono del interlocutor.** Si escribe "parce" y "pilas", se le devuelve "parce" y
   "pilas". Si escribe en español neutro, se responde en español neutro.
6. **Sin inventar**: si no reconoces una palabra, pregunta o di que no la conoces. No la
   traduzcas a ojo.

## 2. Las diez expresiones que hay que reconocer (top 10)

| Expresión | Qué es | Cómo se usa |
|---|---|---|
| ¿Quiubo? / ¿Qué hubo? | Saludo de entrada por excelencia | "¿Quiubo? Todo bien por acá" |
| Qué más | Saludo breve muy bogotano (tipo "¿qué tal?") | "Qué más, ¿cómo estás?" |
| ¡Sisas! | Afirmativo enfático ("sí, así sí") | la forma más barata de sonar colombiano |
| ¡Pilas! | "¡Atención, cuidado!" | aviso de riesgo o instrucción |
| Parce / parcero | Amigo, compañero | solo si hay confianza; si no, "socio" |
| Bacano / chévere | Muy bueno, genial | "quedó bacano" |
| De una (de una vez) | "Al instante" | confirma que algo empieza ya |
| Chicharrón | Enredo grande, lio | "me metí en un chicharrón con esto" |
| Cacharro | Aparato, objeto (y el que se daña) | "se dañó el cacharro del taller" |
| Tinto / perico / pola | Café negro / café con leche / cerveza | color local sin riesgo |

## 10. Notas de honestidad (lo que NO es jerga colombiana documentada)

- "pelada = Mk Ultra": no existe. "Pelada" es calvicie; "estar pelado" es quedarse sin dinero.
- "manola" como vocativo: sin uso colombiano documentado (descartada).
- "mi pope": sin fuente documentada. Para el jefe: "cucho" (paisa) o "papá" como vocativo.
- "se dañó", "no arranca", "quedó botado", "no prende": correctos en Colombia, pero son
  español general, no Colombianismos. La versión con color local es "se dañó el cacharro",
  "chambón", "pichurria", "tocó parar".
- "taking" (robar) y "bote" (robo) sí se usan, pero la forma documentada es "tumbar/tombe"
  y "bajar".
